# Digital Library Management System

## Project Information
**Course:** EF101 – IT Fundamentals  
**Project:** Digital Library Management System  
**University:** NED University of Engineering and Technology

## Project Description
A relational database management system developed using MySQL. The project is designed to manage library operations, including books, authors, publishers, categories, book copies and related records.

## Technologies Used
- MySQL – Database Management System
- XAMPP – Local Server Environment
- phpMyAdmin – Database Administration Interface
- SQL – Database Queries and Operations

## Database Features
- Relational database design
- Multiple interconnected tables
- Primary and foreign key constraints
- Data insertion and management
- SELECT queries and data retrieval
- UPDATE and DELETE operations
- Referential integrity
- Management of books and their copies

## Project Files
- `digital_library.sql` – SQL source code containing database structure, queries and sample data.
